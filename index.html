GitHub에 저장

이 저장소에만, "Contents: Read and write" 권한만 부여한 fine-grained PAT을 권장합니다. 토큰은 이 HTML 파일 텍스트에는 저장되지 않고, Claude의 개인 저장소(계정별로 격리됨)에만 저장되며, 저장소/브랜치는 코드 상단 CONFIG 값으로 고정되어 있습니다.

이메일 초안 열기

메일 앱은 서식 있는 표를 직접 넣어주지 못하기 때문에(mailto 규격의 제약), 본문에는 표 형태의 텍스트가 채워집니다.
실제 표 모양 그대로 붙여넣고 싶다면 "📋 표로 복사"를 누른 뒤, 메일 본문에 붙여넣기(Ctrl+V / ⌘V) 하세요. Gmail·Outlook 등 서식 있는 편집기에서는 진짜 표(테두리 포함)로 붙습니다.
또한 이 창을 열 때 엑셀 파일이 자동으로 다운로드됩니다. 브라우저 보안 정책상 메일에 파일을 자동으로 첨부할 수는 없으니, 다운로드된 파일을 메일 작성 창에 직접 첨부해주세요.

이메일 템플릿 설정

사용 가능한 값: {{week}} (예: 2026-W35), {{range}} (예: 8/31 ~ 9/4), {{content}} (표 형태로 정리된 본문 전체 — 각 열이 " | "로 구분된 표 텍스트입니다). 이 값들은 이메일 초안을 열 때 실제 값으로 자동 치환됩니다. 서식이 살아있는 진짜 표가 필요하면 이메일 창의 "📋 표로 복사" 버튼을 이용하세요.
